# Documentation screenshots

These are unedited captures of Awaker's built-in demo, using synthetic league names, rosters, scores, and projections. No personal account or service credentials appear in them.

- `watchroom.png`: default theme, game-day player watchroom.
- `week-in-review.png`: a finished week for a whole league, with points left on benches and start/sit calls graded against what was projected before kickoff.
- `trade-finder.png`: going after a named player, including the case where every route costs more than he adds.
- `trade-builder.png`: sample package comparison, including the warnings that a pickup would have done the same job and that the package is outside the configured value limit.

Refresh these screenshots when the interface changes. Player photos are loaded from Sleeper's CDN and retain their owners' rights. Screenshots illustrate the interface, not live scores or guaranteed outcomes.
