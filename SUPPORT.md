# Getting help

- **Questions, setup help, and ideas:** start a thread in
  [Discussions](https://github.com/afk-sapien/awaker/discussions).
- **Bugs:** open a [bug report](https://github.com/afk-sapien/awaker/issues/new/choose)
  with your Awaker version, hosting mode, and reproduction steps. Remove tokens and
  private league data.
- **Security issues:** report them privately as described in [SECURITY.md](SECURITY.md).

Start with the [README](README.md) and [self-hosting](docs/self-hosting.md). Awaker is
maintained in spare time, so replies are best effort.
